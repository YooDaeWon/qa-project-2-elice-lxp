호출 규약 · 인증 안내

인증: 모든 로그인 필요 API는 Authorization: Bearer <sessionkey> 헤더를 사용합니다. sessionkey는 로그인 시 account 서비스가 발급하는 세션 키이며, 브라우저 로그인 후 개발자도구 네트워크 탭의 요청 헤더에서 그대로 확인할 수 있습니다. (API 키·JWT 별도 발급 없음)

엔드포인트별 AUTH 태그

태그의미
AUTH Full로그인 세션 필수 — Verified 상태 계정만 허용
AUTH Light로그인 세션 필수 — 세션 정보만 사용(계정 전체 조회 없음)
AUTH Skip인증 불필요 — 비로그인 호출 가능
AUTH Bearerclassroom 서비스: Bearer 토큰 필수

공통 헤더: 기관 식별을 위해 x-elice-org-name-short 헤더를 함께 보냅니다 (예: qatrack). 파라미터 표의 In 열이 header인 항목이 이에 해당합니다.

응답 형식: 성공 시 모델 JSON을 그대로 반환하고, 실패 시 _ErrorResponseModel(403 인증 / 409 논리 오류 / 422 검증 / 500 서버)이 내려옵니다.

예시 출처: Response 예시는 서비스가 게시하는 OpenAPI 스키마에서 생성한 형태 샘플입니다 (값은 타입 기본값).

권한(학습자/교육자): 인증을 통과해도 기관 내 역할(Student / TA / HeadTA / Admin)에 따라 거부될 수 있습니다. 이때 HTTP 상태는 200이며 본문의 fail_code가 insufficient_permission으로 내려옵니다 — 상태 코드만 보고 성공으로 판단하지 마십시오.
